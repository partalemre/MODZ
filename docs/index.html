Installing with an AI agent

Ask your agent to "install MODZ". It can follow llms.txt, which holds these steps:

  1. Check that claude --version is 2.1.295 or later. If not, ask the person to update.
  2. Run claude plugin marketplace add partalemre/MODZ.
  3. Run claude plugin install modz@modz, then claude plugin install <name>@modz for each mod the person wants.
  4. Merge optional settings into the env block of ~/.claude/settings.json, keeping what is there.
  5. Check that claude plugin list shows each mod enabled, then ask the person to start a new session.
{ "env": {
  "MODZ_LANG": "tr",            // optional: Turkish interface
  "CLAUDE_CODE_ARTIFACT": "1"   // transceiver inside an SDK host or IDE
} }
